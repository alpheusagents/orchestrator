# OpenCode V1 Reference

OpenCode V1 (`1.x`) uses the `task` tool and the singular `agent` config. It is not the V2 `subagent` / `agents` schema.

This reference supports the `orchestrator-adapter-opencode` adapter. The adapter's `Dispatch Mapping` is authoritative for host targets; its `Permissions` section is recommended setup and the user applies it. This page covers that setup, built-in agents, resume caveats, and command registration. The orchestrator never edits host configuration.

## Agent configuration

Recommended; the user applies it.

- Define role agents under `agent` in `opencode.json` or `opencode.jsonc`.
- Alternatively, use Markdown agents under `.opencode/agents/<name>.md` (project) or `~/.config/opencode/agents/<name>.md` (global). V1 also discovers `agent/`, `mode/`, and `modes/` directories.
- Recommend `mode: "subagent"` on each role agent. If omitted, the mode defaults to `all`, so the agent can appear as a primary.
- Recommend pinning `model` on the role agent.

## Built-in agents

- `explore` is built-in and read-only.
- `general` is built-in and can write and execute.
- Current stable V1 releases have no built-in `scout`. Some documentation has listed one; do not assume it exists. If a research task needs a read-only agent with network access, recommend a role agent with `edit: deny`, a narrow `bash` policy, and `webfetch` / `websearch` allowed.

## Resume caveats

- Check `opencode --version` and the `task` tool schema in-host before relying on resume.
- The adapter's `Resume` section defines the fresh-worker fallback for releases without a handle.

## Command registration

- Recommended: create `.opencode/commands/orchestrate.md` (V1 also discovers `command/`).
- Let the command load the orchestrator skill and pass the task or plan path as `$ARGUMENTS`.
- Do not invent a command schema; use the current OpenCode documentation.

## No config sample

This page intentionally contains no `opencode.json` sample; the host schema varies by release. Use the official OpenCode documentation for the current syntax.
